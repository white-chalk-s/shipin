# V1.3 规格变更说明：双独立悬浮窗

**当前生效决定：**录制期间使用两个独立悬浮窗。

- **窗口 A（录制控制）：**计时、暂停、停止/保存/丢弃、C/V/F9 快捷键提示、提词框显隐。
- **窗口 B（口播提词）：**显示录前稿件，可单独拖动、调整宽高和字号、滚动、隐藏/恢复。
- **交互：**两个窗不强制贴靠。拖动一个窗，另一个窗不跟随。首次可以默认相邻，但之后分别记住各自位置。
- **跨屏：**可置于不同显示器，断屏/改分辨率后位置安全恢复。
- **录制安全：**两个窗口都不应进入成片；使用 MSS 不能保证天然排除，必须 Windows 实机验证，无法排除的组合阻断录制或采用已验证的安全方案。

**替代旧决策：**V1.2“提词框紧贴 C/V/F9 录制快捷键栏并自动跟随控制窗”不再要求实现。旧 HTML 原型仅用于视觉参考；以本次三份 Markdown 文件为开发依据。

**交付范围：**本压缩包为需求/技术/开发规范，不包含真实安装 EXE，也不声称修改了 HTML 原型。
