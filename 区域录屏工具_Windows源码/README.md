# 区域录屏工具（Windows）

## 本版新增

### 鼠标样式可自定义
主窗口“鼠标样式与点击放大”中可选：
- 箭头
- 手型
- 十字准星
- 高亮圆圈
- 实心圆点
- 不显示

这里设置的是**叠加到录制视频和实时预览里的鼠标样式**，不会改变 Windows 桌面本身的系统鼠标指针。样式设置会自动记住。

### 放大停留时间可自定义
- 可设置 0.5–30 秒，默认 3 秒。
- 鼠标点击录制画面后，约 0.35 秒平滑推进到约 2 倍。
- 在放大状态停留设置的时长。
- 再用约 0.35 秒平滑拉远恢复。
- 一次完整效果总时长 = 停留时长 + 约 0.7 秒动画。
- 时长会自动记住。

### 可以停止但不保存
悬浮控制面板提供“停止并删除本次视频”。点击后直接停止录制并删除本次生成的视频，不再弹出模态确认框，避免确认框被置顶控制面板遮挡而看起来卡住。该按钮只影响当前这段录制；快捷键 F9 和“停止并保存”仍然会保存文件。

### 文件名默认按时间戳命名
默认格式示例：`录屏_显示器1_20261022_111512.mp4`。如果同一秒内文件名冲突，会自动加序号。保存目录可在主界面更改。

## 其他功能
- 自动检测连接的显示器，可选择固定录制哪一块屏幕。
- 可开启鼠标跟随切屏和自动识别鼠标所在窗口内容区。
- 可视化框选并记忆自定义区域预设。
- 实时预览、暂停/继续、重新选择区域。
- 只录画面，不录系统声音或麦克风。
- 默认保存到 `视频\区域录屏`。

## 运行源码
1. 在 Windows 10/11 安装 Python 3.11 或 3.12（64 位）。
2. 解压 ZIP。
3. 双击 `run_windows.bat` 安装依赖并运行。

## 打包成 EXE
在 Windows 电脑上双击 `build_windows.bat`。打包完成后，程序位于 `dist\区域录屏工具.exe`。

## 注意事项
- 当前代码已通过 Python 语法检查，但尚未在实际 Windows 双屏环境实测。
- 鼠标样式会绘制到输出视频中，不会修改系统光标本身。
- “停止，不保存”会在录制停止后删除该次 MP4；如果程序在删除前异常退出，可能残留未完成文件。
- 部分受保护内容、管理员权限窗口和特殊硬件加速窗口可能无法正常捕获。


## 修复：停止不保存时界面像卡住
- 移除了悬浮置顶窗口触发的模态确认框，避免确认框被遮挡或焦点异常。
- 按钮改为“停止并删除本次视频”，点击即停止当前录制，结束后删除当前 MP4。
- 停止过程中，控制面板会显示“正在停止并删除本次视频，请稍候…”，按钮会禁用，避免重复触发。
- 增加了录制线程已刚好结束时的兜底清理处理，并防止结束信号重复清理。
- 本次修改已通过 Python 语法检查与 ZIP 完整性检查；尚未在 Windows 双屏实机测试。


## 新增：录制后简单剪辑与最终导出

录制正常停止并保存后，会自动打开“简单视频剪辑”窗口。也可以从主窗口点击“剪辑已有视频…”选择之前录制的视频。

### 基本操作
1. 使用预览窗口播放/暂停，或拖动进度条定位。
2. 点击“在当前位置分割”，把当前选中片段拆成两段。
3. 在右侧片段列表选中不需要的片段，点击“删除选中片段”。
4. 如误操作，点击“撤销”；点击“恢复全部”可回到完整原视频。
5. 点击“导出最终 MP4”，选择文件名和保存位置。

### 剪辑行为
- 删除的片段不会写入最终视频，剩余片段会按原始时间顺序无缝拼接。
- 原始录屏保持不变，最终视频会另存为一个新的 MP4 文件。
- 剪辑基于视频帧，不提供音频轨道编辑；本工具录制时本来就不录制声音。
- 导出时会重新编码视频，耗时取决于视频时长、分辨率和电脑性能。
- 已支持播放预览、帧定位、分割、删除、撤销、恢复全部和导出进度显示。
