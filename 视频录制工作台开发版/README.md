# 视频录制工作台开发版

这是从 `区域录屏工具_Windows源码` 复制出的开发基线；原始源码未修改。当前录制工作台已按原型重建，尚不是 V1.3 的完整实现，不能作为正式发布版本。

## 已完成

- 整屏录制不再套用旧裁切设置；框选时在松开后可拖动选区或边缘调整，点击“保存选区”或按 Enter 确认，Esc 取消。框选坐标按各显示器 DPI 换算成实际捕获像素。

- 录制、剪辑、导出及历史页面使用顶部导航和固定工作区；录制页一屏展示显示器、录制范围、C/V 快捷键、保存位置、预览、稿件与开始操作。窗口选择及区域预设只在对应范围下显示。录制首页不再提供自动切屏、自动识别窗口及录前裁切；支持选择鼠标样式、放大倍率和停留时间，以及高亮样式。剪辑裁剪仍保留。剪辑属性和历史列表必要时在区域内滚动。
- 剪辑页使用“画面 / 文字”两个标签。阶段文字固定在输出画面顶部，公共样式支持背景色、文字色和对齐；可在播放头处添加阶段并拖动阶段轨两端设置时间。选择原始、常用或自定义比例，并选择完整显示或填满裁切；预览、剪辑 MP4 和交付导出共享处理逻辑，工程保存这些设置。旧工程中的自由标注保留并继续导出，但新界面不再新增此类标注。
- 剪辑页提供可点击的片段时间线、剪后预览、分割、删除、播放头设为起点/终点、撤销和恢复；录制页与剪辑页共用一份口播稿。导出仍使用原有的 OpenCV `mp4v` 路径。
- 支持在剪辑页创建工程，通过顶部导航打开工程；工程包含独立复制的原素材、剪辑片段、标注及口播稿，修改后自动保存。未创建工程时，切换视频或退出会提示未保存的剪辑操作。
- 工程清单和稿件采用原子写入，并保留稿件快照；写入中断造成清单与稿件不一致时可恢复上一次成功保存的稿件。录前草稿与已打开工程的稿件分别保存。当前仅支持本开发版的 1.0.0 工程格式；不支持的标注格式会拒绝打开，避免丢失数据。
- 剪辑页支持点击画面标注选中并拖动位置、拖动右下角缩放，按 Delete 或点击删除；标注轨两端可拖动调整显示时间。画面裁剪通过拖动上下左右边缘调整，对整段视频生效，预览、工程和导出保持一致。支持在画面点击添加文字、箭头、矩形框和简单贴纸，并可调整内容、原素材开始时间、时长、位置、大小、颜色及图层顺序；标注轨可选择标注，操作可撤销。标注使用原素材时间，删去的片段不会显示标注；恢复片段后原标注可再次显示。预览、剪辑 MP4 和交付导出使用同一绘制逻辑。
- 历史项目展示最近 30 个工程、创建和修改时间以及从素材首帧生成的预览；支持双击或按钮重开、定位目录、失效后重新定位及移出列表（不会删除工程）。列表和最近交付目录保存在本机用户设置中。
- 导出交付页生成无声 30 FPS H.264 `video.mp4`、UTF-8 `script.txt` 和 `handoff.json`。编码在后台线程执行；使用 ffprobe 读取并校验实际视频流、帧率和时长，通过后才提交完整目录。可在编码或校验期间取消，程序会清理临时目录并保留原素材。空稿不能交付。画面保持正常速度，口播时长匹配由下游处理。
- 录制用单调时钟统计有效时间，暂停时间不计入；采集与编码并行，仅保留最新采样帧，采样不足时重复帧以维持恒定帧率。失败时保留临时素材并提示目录，丢弃时取消编码。剪辑窗口显示实际采集帧率和补帧数量。
- 录制中可按 C 高亮鼠标位置、按 V 放大该位置；暂停、控制窗开关关闭及本程序窗口取得焦点时不触发。Ctrl/Alt/Win 组合键和长按重复不会触发；鼠标左键不再触发放大。全局按键不会被拦截，目标程序仍会收到 C/V，输入文字前可在控制窗关闭效果。
- 录前可输入或导入 UTF-8 口播稿并自动保存本地草稿。录制时使用独立控制窗与只读提词窗，可分别移动；提词窗支持缩放、字号、滚动、隐藏与恢复，两窗位置分别记忆。控制窗显示录制计时。
- 开始录制前对两个实际悬浮窗逐一进行 MSS 捕获排除检查；无法验证时阻止开始。恢复隐藏提词窗时重新设置排除标志。
- 指定窗口模式可选择所选显示器内的可见窗口，并跟踪其内容区移动；关闭、最小化、隐藏或超出该显示器时停止并保留临时素材。MSS 读取屏幕上的可见像素，其他窗口遮挡目标时遮挡内容也会被录入。
- 增加时间线单元测试、基于合成视频的剪辑和导出集成测试，以及 Windows 捕获排除、短时录制探针。

## 启动与验证

建议使用 Windows x64 Python 3.11 或 3.12 建立独立虚拟环境并安装 `requirements.txt`；该文件目前只有最低版本约束，尚不是发布锁定依赖。创建后可双击 `run_dev.bat`。

交付功能在开发版优先查找 `vendor/ffmpeg` 下的 `ffmpeg` 和 `ffprobe`，也可使用系统 PATH 中的程序；需要具备 `libx264` 编码能力。正式安装包的编码器来源、许可证和离线打包尚未完成。

## 开发打包与候选安装包

安装锁定的构建依赖后，执行 `powershell -ExecutionPolicy Bypass -File .\packaging\build_dev.ps1`。每次构建使用新的 `artifacts/dev-*` 目录，生成 PyInstaller onedir，并用临时用户数据启动主窗口做隔离检查。当前锁定环境为 Python 3.12 和 `requirements.lock.txt`；它记录已验证环境的确切版本，但尚未包含包哈希，不能视为完整的发布供应链锁定。

`packaging/build_release.ps1` 是候选安装包构建入口，要求本机安装 Inno Setup 6、依赖与锁定文件一致，以及提供具备 `libx264` 的 FFmpeg 和 ffprobe。编码器目录须含 `PROVENANCE.json`（格式见 `packaging/PROVENANCE.example.json`）、两份二进制的 SHA-256 和非空的 `THIRD_PARTY_NOTICES.md`；这些文件须先完成真实来源及许可证审核，脚本检查文件和哈希并不代替法律或分发审核。脚本运行测试、开发构建与启动检查后再调用 Inno Setup。输出只属于候选包，仍须在干净 Windows 10/11 机器验证安装、升级、卸载、数据保留和离线交付。

本机开发构建中，PyInstaller 收集的同名 ICU DLL 与 Qt 所需的 Windows 系统 ICU 接口冲突；构建脚本把该 DLL 移到构建工作目录，让程序使用系统 ICU。其他 Windows 版本仍需实测，尤其是较旧的 Windows 10。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe region_recorder.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
$env:PYTHONPATH = '.'
.\.venv\Scripts\python.exe tests/probe_capture_exclusion.py
.\.venv\Scripts\python.exe tests/probe_recording.py
.\.venv\Scripts\python.exe tests/probe_frame_content.py
.\.venv\Scripts\python.exe tests/probe_effects.py
.\.venv\Scripts\python.exe tests/probe_global_hotkeys.py
.\.venv\Scripts\python.exe tests/probe_two_windows.py
.\.venv\Scripts\python.exe tests/probe_recording_windows.py --monitor 1
.\.venv\Scripts\python.exe tests/probe_window_capture.py
.\.venv\Scripts\python.exe tests/probe_editor_flow.py
```

捕获排除探针会短暂显示彩色测试窗；录制探针会短暂捕获主屏并将视频写入临时目录，测试后删除。探针只是本机实验，无法替代单/双屏、DPI、Windows 版本和不同录制范围的人工验收。

## 本机基线（2026-10-28）

- 已建立独立 Python 3.12 虚拟环境；自动化测试覆盖工程保存恢复、历史工程移动后重新定位及真实 H.264 交付与失败清理；暂停、丢弃及画面颜色顺序短录通过。Python 3.14 环境曾出现图形测试完成后进程异常退出。
- 单个 Qt 测试窗通过 `SetWindowDisplayAffinity(0x11)` 后，本机 MSS 捕获中测试色块从 100% 降为 0%。不能据此断言其他捕获场景或机器安全。
- 主屏 1920×1200、目标 30 FPS：改造前约 5 秒短录生成 2.93 秒视频；改造后有效时间 5.005 秒、视频 5.00 秒。Python 3.12 含暂停短录中，有效时间 2.906 秒、视频 2.90 秒。
- 旧二次编码方案的五分钟基准：有效录制 299.991 秒，成片 300 秒；总耗时 415.149 秒，整理约 115 秒。并行方案的 10 秒短录：有效录制 9.998 秒，成片 10 秒，总耗时 10.146 秒。
- 并行方案五分钟基准（Python 3.12、1920×1200，添加诊断显示之前）：有效录制 299.994 秒，成片 300 秒、9000 帧；从启动到成片校验完成总耗时 300.224 秒。不同负载、分辨率或机器下性能仍需验证。
- 实时编码当前仍使用 OpenCV `mp4v`；低采集帧率时通过重复画面保持时长，不能提升画面流畅度。编码性能不足可能使停止后产生追帧等待。H.264 和安装包中的编码器分发方案尚未完成。
- 本机录制样片验证 C 高亮、V 放大及放大期间的 C 高亮；Windows 全局监听探针中 Ctrl+C 未触发效果事件，单键 V 可触发事件。多显示器和不同 DPI 下的鼠标位置仍需实测。
- 本机双屏（主屏 150%、副屏 100%）分别录制全屏并将两个窗口放入画面，测试标记未出现在成片中；录制中隐藏与恢复提词窗不停止录制。其他 Windows 版本、显示器热插拔、区域/窗口捕获及长时间场景仍需验证；单次启动前的检查不等于所有环境均已验证。
- 口播稿在录制页与剪辑页共享，打开或创建工程后保存到工程目录。标注的字体和不同 DPI 显示效果仍需 Windows 实机验收；下游工具实际联调和安装器尚未实现，不能宣称 V1.3 完成。
- 本机短录验证了录制停止后进入嵌入式剪辑页、原素材可读取及录前稿件同步；合成视频测试覆盖跨片段剪裁、删除、撤销及导出帧数。
- 本机测试窗口移动时内容区跟随，最小化后停止并保留临时素材；受保护内容、窗口遮挡、多屏边界和更多真实软件仍需验证。自定义区域支持选择预设或开始后框选，整屏选择不会被旧预设覆盖。录制前画面是手动刷新的一次静态截图。
